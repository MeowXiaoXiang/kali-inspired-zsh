# 開發與驗證

[回首頁](../README.md)

## 專案範圍

維持一份可讀的 .zshrc，提供雙行提示符、時間、Git 資訊、指令耗時與退出碼、可關閉的負載提示、自適應路徑縮短，以及兩個可獨立關閉的 Zsh 插件。保留 extract、mkcd、pkgup、pkgclean。

目前不以 Windows 原生 Shell、macOS 或完整 Shell 框架為目標。發行版支援宣告以實測為準。

所有文字檔使用 UTF-8 無 BOM、LF 與檔尾換行。.gitattributes 控制換行，.editorconfig 提供編輯器預設。個人的 .zsh_config、.zsh_aliases、.zsh_local 不提交、不覆蓋；認證資料也不寫入專案或測試紀錄。

## 行為約定

- 初始化前載入 .zsh_config；預設按鍵後載入個人 alias 與覆寫，最後載入插件。
- 缺少插件不影響基本啟動；非互動式載入略過互動初始化。
- 外部路徑、Git 分支與環境名稱以文字顯示，維持關閉 PROMPT_SUBST。
- Git 快取保留在目前 Shell，預設 3 秒失效；目錄、分支或 HEAD 變更會重新查詢。
- Git 狀態逾時顯示 ~，其他失敗顯示 !；只有工作區狀態查詢有逾時限制，裸儲存庫不當成一般工作區。
- 負載的空結果也要快取，計算使用 Zsh 內建運算。
- 路徑保留 Linux 寫法與完整目錄名稱。過窄的終端機或過長的單一名稱允許換行。
- 管線退出碼沿用最後一個指令，不啟用 PIPE_FAIL。
- 套件函式辨識發行版，保留套件管理器的確認流程；前一步失敗就停止，不在啟動時自動執行。
- 解壓保留原壓縮檔、不覆蓋同名檔案。tar 衝突會失敗，zip 略過同名檔案；可能部分完成，不提供回滾或不受信任壓縮檔的隔離環境。

## 執行測試

需要 Zsh 5.9、Git、Python 3、tar、gzip、bzip2、xz 與 unzip。

```sh
python3 tests/test_zsh.py
```

要納入真實插件的載入、輸入元件、重複載入、獨立開關及互動式測試，設定插件目錄：

```sh
ZSH_TEST_PLUGIN_ROOT=/path/to/plugins python3 tests/test_zsh.py
```

上述路徑是佔位文字，請替換成實際位置。目錄應包含：

```text
plugins/
├── zsh-autosuggestions/zsh-autosuggestions.zsh
└── zsh-syntax-highlighting/zsh-syntax-highlighting.zsh
```

沒有設定這個變數時，兩項需要真實插件的測試會略過，互動式測試不載入插件。要重現完整驗證，必須提供插件目錄。

測試使用臨時家目錄、Git 儲存庫、實際壓縮檔與虛擬終端機，不更改日常設定或登入 Shell。套件指令分派與失敗處理使用替代的 sudo 函式測試；原生套件管理另使用模擬／拒絕交易模式預覽，避免測試順便升級或移除套件。

## 驗證紀錄

2026-10-23 的程式驗證包含真實插件，沒有略過測試：

| 平台 | Zsh | 結果 |
|---|---|---|
| Ubuntu 26.04.1 WSL2 | 5.9 | 23 項通過 |
| Fedora 44 WSL2 | 5.9 | 23 項通過 |

涵蓋快取、分支切換、Git 衝突與同步狀態、裸儲存庫、連結工作樹、逾時與錯誤、文字轉義、路徑與窄終端機、個人覆寫、插件開關、實際解壓與同名保護、套件分派，以及真實互動式退出碼／耗時。

套件函式的驗證採模擬方式：APT 升級與移除依賴的模擬成功；DNF 升級預覽刷新中繼資料後按設定拒絕交易，移除依賴則回報無事可做。清快取的指令選擇以替代函式驗證，這輪函式驗證沒有實際清快取或升級套件。Fedora 額外安裝了 xz，以測試全部解壓格式。

已測試的平台僅限上表，其他發行版尚未測試。文件更動不代表重新跑過程式測試，紀錄應註明實際驗證的範圍。
